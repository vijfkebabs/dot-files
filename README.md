# dot-files
 
Personal dotfiles and configuration files for my setup: a Wayland desktop on Arch (CachyOS) or NixOS with [Hyprland](https://hypr.land/) and a Windows setup with Windhawk and YASB. Almost everything on the Linux side is themed from the current wallpaper with [wallust](https://codeberg.org/explosion-mental/wallust).

> [!NOTE]
> The Linux configs are tested on Arch Linux and NixOS and are built around **wallust**, **awww** and **waypaper**. They will not work properly without them.
> This does not apply to fastfetch, WezTerm, Windhawk and YASB.

## Usage
 
Clone the repo:
 
```bash
git clone https://github.com/vijfkebabs/dot-files.git
cd dot-files
```
 
Then copy or symlink each folder to its place (back up your own configs first). Exact paths are listed per tool below. On NixOS, follow the [NixOS](#nixos) section instead, which does the linking for you.
 
## Linux desktop
 
### Dependencies
 
Used by the Hyprland config and its keybinds: `hyprland`, `awww` (+ `awww-daemon`), `waypaper`, `wallust`, `waybar`, `rofi`, `swaync`, `kitty`, `hyprshot`, `hyprpicker`, `hyprpolkitagent`, `brightnessctl`, `playerctl`, `wpctl` (PipeWire), `nm-applet`, `udiskie`, `syncthing`, `hyprtasking` (via `hyprpm`) and `quickshell`. Install what you actually use.
 
The fonts are JetBrainsMono Nerd Font.

For the terminal tools ([Neovim](#neovim) and [Yazi](#yazi)): `neovim` (0.11+), `yazi`, `git`, a C compiler (`base-devel`), `tree-sitter-cli`, `ripgrep`, `fd`, `lazygit`, `fzf`, `zoxide`, `ffmpeg`, `7zip`, `jq`, `poppler`, `imagemagick` and `udisks2` (for the Yazi mount plugin).
 
### Hyprland
 
`hypr/` is a Lua config. It needs a Hyprland version with Lua config support.
 
```bash
ln -sfn "$PWD/hypr" ~/.config/hypr
hyprctl reload
```
 
| Path | Purpose |
| --- | --- |
| `hyprland.lua` | Main config: monitor, autostart, general/decoration/animations, input (Belgian + US layout), keybinds and window rules |
| `colors.lua` | **Generated by wallust.** Provides the border colors; `hyprland.lua` falls back to default colors if it is missing |
| `variables.lua`, `scheme/` | Caelestia-style variables and color scheme (`default.lua`, `current.lua`) |
| `hyprland/` | Modular split of the config: `animations`, `decoration`, `env`, `execs`, `general`, `gestures`, `group`, `input`, `keybinds`, `misc`, `rules` |
| `utils/` | Helper modules (`functions.lua`, `json.lua`) |
| `scripts/wall.sh` | Sets the wallpaper with awww, runs wallust, then reloads Hyprland |
 
Some keybinds (`SUPER` is the main modifier):
 
| Keys | Action |
| --- | --- |
| `SUPER + Space` | Rofi app launcher |
| `SUPER + T` | Terminal (kitty) |
| `SUPER + W` / `SUPER + SHIFT + W` | Waypaper / random wallpaper |
| `SUPER + P` / `SUPER + SHIFT + P` | Region screenshot / color picker |
| `SUPER + N` | Toggle notification center |
| `SUPER + K` | Switch keyboard layout |
| `SUPER + 1-0` (number row) | Switch workspace (`SHIFT` moves the window) |
| `ALT + Tab` | Cycle windows |
 
Keybinds are written like this:
 
```lua
local mainMod = "SUPER"
 
hl.bind(mainMod .. " + space", hl.dsp.exec_cmd("rofi -show drun"))
hl.bind(mainMod .. " + T", hl.dsp.exec_cmd("kitty"))
```
 
### Wallust (dynamic theming)
 
`wallust/wallust.toml` registers one template per app. Running wallust on an image renders each template and writes it to the target below:
 
| Template | Output |
| --- | --- |
| `colors.lua` | `~/.config/hypr/colors.lua` |
| `waybar.template.css` | `~/.config/waybar/wallust/colors-waybar.css` |
| `colors.rasi` | `~/.config/rofi/colors.rasi` |
| `colors-kitty.conf` | `~/.config/kitty/colors-kitty.conf` |
| `nvim.lua` | `~/.config/nvim/colors/wallust.lua` |
| `colors-swaync.css` | `~/.config/swaync/style.css` |
| `colors.json`, `colors` | `~/.cache/wallust/` (for editor tooling) |
| `colors-pywalfox.json` | `~/.cache/wal/colors.json` (Pywalfox) |
| `btop.theme` | `~/.config/btop/themes/wallust.theme` |
| `vencord.theme.css` | `~/.config/Vencord/themes/wallust.theme.css` |
| `spicetify.ini` | `~/.config/spicetify/Themes/wallust/color.ini` |
 
Setup:
 
```bash
mkdir -p ~/.config/wallust
cp -r wallust/. ~/.config/wallust/
```
 
Change the wallpaper and re-theme everything with the included script:
 
```bash
~/.config/hypr/scripts/wall.sh /path/to/wallpaper.png
```
 
It runs `awww img`, `wallust run` and `hyprctl reload`. To use it from Waypaper, set it as the post command with `$wallpaper` as the argument.
 
After wallust runs:
 
- **Kitty, Waybar, Rofi, Hyprland:** pick up the new colors on reload or next launch.
- **Neovim:** run `:colorscheme wallust` (or restart Neovim) to load the new colors.
- **Vencord:** enable `wallust.theme.css` under Settings → Vencord → Themes once.
- **btop:** set `color_theme = "wallust"` in `btop.conf` and restart btop.
- **Spicetify:** run `spicetify apply` to load the new `color.ini`.
### Waybar

ln -sfn "$PWD/waybar" ~/.config/waybar

```bash
ln -sfn "$PWD/kitty" ~/.config/kitty
```

### Neovim

`nvim/` is a [LazyVim](https://www.lazyvim.org/) setup. Plugins are installed by lazy.nvim on first launch and pinned by `lazy-lock.json`. You need Neovim 0.11 or newer, plus the tools from the [dependencies](#dependencies) list.

```bash
# back up an existing config first
mv ~/.config/nvim ~/.config/nvim.bak
ln -sfn "$PWD/nvim" ~/.config/nvim
nvim
```

Wait for lazy.nvim to finish installing, restart Neovim, then run `:LazyHealth` to check that everything is OK.

| Path | Purpose |
| --- | --- |
| `init.lua` | Entry point, loads `config.lazy` |
| `lua/config/` | `lazy.lua` (plugin manager bootstrap), `options.lua`, `keymaps.lua`, `autocmds.lua` |
| `lua/plugins/` | Your own plugin specs. `colorscheme.lua` sets the LazyVim colorscheme to `wallust` |
| `colors/wallust.lua` | **Generated by wallust.** Colorscheme made from the current wallpaper |
| `lazyvim.json`, `lazy-lock.json` | LazyVim extras and locked plugin versions |
| `stylua.toml` | Formatting rules for the Lua files |

> [!NOTE]
> The colorscheme is set to `wallust`, so run wallust once (see [Wallust](#wallust-dynamic-theming)) before the first launch. Without `colors/wallust.lua`, LazyVim falls back to its default colorscheme. Inside `colors/wallust.lua`, set `transparent = true` to let the terminal background show through.

Handy keys (`<leader>` is `Space`):

| Keys | Action |
| --- | --- |
| `<leader><space>` | Find files |
| `<leader>/` | Grep in project |
| `<leader>e` | File explorer |
| `<leader>gg` | lazygit |
| `<leader>l` / `<leader>cm` | Lazy plugin manager / Mason |
| `:LazyExtras` | Enable language packs |

### Yazi

`yazi/` configures the [Yazi](https://yazi-rs.github.io/) file manager.

```bash
ln -sfn "$PWD/yazi" ~/.config/yazi
```

Install the plugins listed in `package.toml` (they are also bundled in `yazi/plugins/`):

```bash
ya pkg install
```

| Path | Purpose |
| --- | --- |
| `yazi.toml` | Registers the `git` fetchers that show git status next to files |
| `keymap.toml` | Custom keybinds (below) |
| `init.lua` | Sets up the `full-border` and `git` plugins |
| `package.toml` | Plugin list with pinned revisions |
| `plugins/` | `chmod`, `full-border`, `git`, `mount`, `smart-enter`, `toggle-pane` |

Custom keybinds:

| Key | Action |
| --- | --- |
| `l` | `smart-enter`: open files and enter folders with one key |
| `T` | `toggle-pane`: maximize the preview pane |
| `c` | `chmod`: change permissions |

The `mount` plugin has no keybind yet. To mount and unmount drives from Yazi, add this to `keymap.toml`:

```toml
[[mgr.prepend_keymap]]
on  = "M"
run = "plugin mount"
```

Start Yazi with `y` instead of `yazi` to have your shell change into the folder you were in when you quit. The wrapper is defined in `fish/config.fish`. Use `Q` to quit without changing directory.

> [!NOTE]
> Image, video and PDF previews need a terminal with an image protocol (kitty and WezTerm work) and the preview tools from the [dependencies](#dependencies) list.

### Spicetify
 
Follow the [Spicetify install instructions](https://spicetify.app/docs/getting-started), then:
 
```bash
mkdir -p ~/.config/spicetify
cp -r spicetify/Themes spicetify/CustomApps ~/.config/spicetify/
 
spicetify config current_theme wallust color_scheme wallust
spicetify apply
```
 
Themes: `Ziro`, `caelestia`, `marketplace` and the wallust-driven `wallust` theme. To use another one, change `current_theme` (and `color_scheme` if the theme has several).
 
> [!WARNING]
> `config-xpui.ini` contains absolute paths from my machine (for example `prefs_path` and `spotify_path`). Don't copy it over your own config. Compare it and keep your paths.
 
### Vencord
 
- `Vencord/themes/wallust.theme.css`: copy to your Vencord themes folder (Settings → Vencord → Themes → Open Themes Folder) and enable it.
- `Vencord/settings/quickCss.css`: paste into QuickCSS, or copy to `~/.config/Vencord/settings/`.
- `Vencord/settings/settings.json`: copy to `~/.config/Vencord/settings/` while Discord is closed.
Vesktop and Flatpak installs use different folders, so use the **Open Themes Folder** button to find yours.
 
## NixOS
 
On NixOS the Linux configs are linked by a flake using [Home Manager](https://github.com/nix-community/home-manager). Each program has its own module in `modules/`, and `flake.nix` exposes them together as `homeManagerModules.default`.
 
| Module | Installs | Links |
| --- | --- | --- |
| `modules/hypr.nix` | none (Hyprland comes from the system config) | `~/.config/hypr` |
| `modules/kitty.nix` | `kitty` | `~/.config/kitty` |
| `modules/rofi.nix` | `rofi` | `~/.config/rofi` |
| `modules/waybar.nix` | `waybar` | `~/.config/waybar` |
| `modules/waypaper.nix` | `waypaper`, `awww` | `~/.config/waypaper` |
| `modules/wallust.nix` | `wallust` | `~/.config/wallust` |
 
The modules use `mkOutOfStoreSymlink`, so `~/.config/<name>` points straight at the cloned repo instead of a read-only copy in the Nix store. This is needed because wallust and waypaper write into those folders. Edits to the config files apply immediately, and `home-manager switch` is only needed after changing a `.nix` file.
 
> [!IMPORTANT]
> The modules expect the repo at `~/Documents/dot-files` and the user `itlab`. If yours differs, change the path in each `modules/*.nix` and the `homeConfigurations.itlab` name, `home.username` and `home.homeDirectory` in `flake.nix`.
 
### 1. System config
 
Add this to `/etc/nixos/configuration.nix` and run `sudo nixos-rebuild switch`:
 
```nix
{ config, pkgs, ... }:
{
  programs.hyprland.enable = true;
  programs.git.enable = true;
  programs.firefox.enable = true;
 
  # Needed for `nix run` and flakes, and for VS Code
  nix.settings.experimental-features = [ "nix-command" "flakes" ];
  nixpkgs.config.allowUnfree = true;
 
  fonts.packages = with pkgs; [ nerd-fonts.jetbrains-mono ];
 
  # Makes Electron/Chromium apps use Wayland
  environment.sessionVariables.NIXOS_OZONE_WL = "1";
}
```
 
### 2. Clone and apply
 
```bash
git clone https://github.com/vijfkebabs/dot-files.git ~/Documents/dot-files
cd ~/Documents/dot-files
git add -A    # flakes only see files tracked by git
nix run home-manager/master -- switch --flake .#itlab
```
 
If Home Manager complains that an existing folder "would be clobbered", move or remove the old folder first (for example `rm -rf ~/.config/kitty` after saving anything you need), or use `-b backup` to keep a copy.
 
After the first run, `programs.home-manager.enable = true` provides the command:
 
```bash
home-manager switch --flake ~/Documents/dot-files#itlab
```
 
### 3. First login
 
1. Log out and choose **Hyprland** in the login manager, or run `Hyprland` from a TTY.
2. Open `waypaper` and pick a wallpaper (or run `~/.config/hypr/scripts/wall.sh <image>`). This runs wallust and generates the color files for Hyprland, Waybar, Rofi and kitty.
3. Reload with `hyprctl reload` if something is not themed yet.
 
### NixOS notes
 
- `swww` was renamed to `awww` in nixpkgs. Use `awww` and `awww-daemon` in any scripts.
- Run `git add` on new files before switching. Untracked files do not exist as far as the flake is concerned.
- Commit `flake.lock` so builds are reproducible.
- Packages are installed per user by Home Manager, so don't also list the same program in `environment.systemPackages`.
- Neovim and Yazi are not managed by the flake yet. Install `neovim` and `yazi` with Home Manager or `environment.systemPackages` and symlink `nvim/` and `yazi/` as shown in their sections.
- Fastfetch, Spicetify and Vencord are not managed by the flake. Set them up with the instructions in their own sections.
 
## Cross-platform
 
### fastfetch
 
Three variants. Pick one and copy its files to `~/.config/fastfetch/`:
 
| Folder | Contents |
| --- | --- |
| `fastfetch/basic/` | `config.jsonc` |
| `fastfetch/advanced/` | `config.jsonc` + `ascii.txt` |
| `fastfetch/cachy specific/` | `config.jsonc` + `logo.txt` |
 
The config references its logo file by path, so keep the logo next to `config.jsonc` (or fix the path inside it).
 
### WezTerm
 
Copy or symlink `WezTerm/wezterm.lua` to:
 
- **Windows:** `%USERPROFILE%\.config\wezterm\wezterm.lua` or `%USERPROFILE%\.wezterm.lua`
- **macOS/Linux:** `~/.config/wezterm/wezterm.lua`
The config sets `powershell.exe` as the default program. On Linux or macOS, remove or change `config.default_prog`. Color scheme is Catppuccin Mocha, and the leader key is `Ctrl + A`.
 
## Windows
 
### Windhawk
 
Install [Windhawk](https://windhawk.net/) and the matching mods, then copy the contents of each JSON file into the **Advanced** tab of the respective mod:
 
- `Win11_taskbar_styler.json`
- `Win11_Start_Menu_Styler.json`
- `Win11_clock_taskbar_customizer.json`
- `Win11_fluent_taskbar_mediaplayer.json`
- `Win11_notification_center_styler.json`
- `Win11_settings_styler.json`
- `Win11_system_tray_tweaks.json`
### YASB
 
```powershell
winget install --id AmN.yasb
```
 
Copy or symlink the contents of `yasb/` to `%USERPROFILE%\.config\yasb\`:
 
- `config.yaml`: bar and widget configuration
- `styles.css`: styling
- `theme.json`: theme configuration
- `Wallpapers/`: wallpapers for the wallpaper widget
The config starts [komorebi](https://github.com/LGUG2323/komorebi) with `whkd` (`komorebic start --whkd`), so install those too, or remove the `komorebi` section. You may also need to update the wallpaper path in `config.yaml`.
 
## Wallpapers
 
`wallpapers/` is a collection of wallpapers. Point Waypaper at it (or at a copy) and pick one with `SUPER + W`.
